경력

대한민국 해군

2025년 6월 – 현재

AI 개발자(군 복무) · LLM 프로젝트 리드

행정 업무와 지식 검색을 지원하는 해군 전군용 LLM 어시스턴트 개발을 이끌고 있습니다. 개발자 7명으로 구성된 팀을 대표해 해군 장성 및 고위 지휘부와의 회의에서 기술 설계, 개발 계획, 프로젝트 방향을 제안합니다.

Open WebUI와 맥락을 고려하는 LLM 파이프라인을 구축했습니다. 지능형 RAG 라우터와 선택적 정책 주입으로 불필요한 컨텍스트 사용을 줄이고, 문서 이해와 작성을 돕는 군사 용어 모듈을 개발했습니다. 이미지 검색과 MMR 검색을 구현해 중복 청크를 줄이고 검색 결과의 다양성과 관련성을 높였습니다.

Open WebUI · RAG · 최대 한계 관련성(MMR)

Aimgonna

2025년 1월 – 2025년 6월

LLM 및 프런트엔드 엔지니어

질의 라우팅과 영양제 추천을 위한 LLM 자동 평가를 구축했습니다. 일반 답변 분기를 추가하고 프롬프트를 개선했으며, 웹 검색 결과를 RAG에 반영해 라우팅 정확도를 70%에서 92%로, 카테고리 일치 점수를 38%에서 52%로 높였습니다. 10가지 건강 데이터 유형을 카드 UI와 모달 편집기로 관리하는 Health Profile 대시보드를 출시했습니다.

LangGraph · LangSmith · React
